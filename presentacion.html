Automatización de ProveMax con Python

De una página web estática a un mini-sistema local que valida pedidos, calcula totales y los archiva automáticamente en Excel.

🐍 Python 3.12 🌶️ Flask 3.1.3 📊 openpyxl 3.1.5 📍 Ejecución local
1

Objetivo

¿Para qué se automatizó?

Reemplazar el backend inexistente de la tienda ProveMax con un servidor local desarrollado en Python + Flask, de modo que los pedidos del cliente ya no se pierdan al cerrar el navegador, sino que se registren automáticamente en un archivo Excel con número de pedido, fecha y total calculado.

🎯

Centralizar datos

El catálogo deja de estar "duro" en el HTML y pasa a un archivo productos.json fácil de editar.

💾

No perder pedidos

Cada pedido queda guardado en pedidos.xlsx con trazabilidad completa.

⚡

Automatizar cálculos

Python calcula subtotales, total y número correlativo sin intervención humana.

2

En qué consiste

La arquitectura y el flujo de la automatización

Antes, el HTML guardaba el carrito en localStorage y solo abría WhatsApp: el pedido nunca se archivaba. Ahora el navegador conversa con un servidor Python mediante una API REST con 3 rutas.

  • →
    GET /api/productos
    Python lee productos.json y devuelve el catálogo en JSON.
  • →
    POST /api/pedidos
    Recibe el carrito, valida, calcula el total y lo escribe en Excel.
  • →
    GET /api/pedidos
    Devuelve un resumen de los pedidos registrados.
app.py 
@app.route("/api/pedidos", methods=["POST"])
def api_pedidos():
    data  = request.get_json(silent=True) or {}

Flujo paso a paso

PASO 1

Cliente elige

Selecciona productos y arma el carrito en la web.

PASO 2

Envía pedido

Pulsa "Solicitar pedido". El navegador hace un POST a Flask.

PASO 3

Python procesa

Valida, calcula total y escribe la fila en pedidos.xlsx.

PASO 4

Confirma

Devuelve el N° de pedido y la web abre WhatsApp con el detalle.

Conclusiones

Aprendizajes y resultados obtenidos
✓

Automatización efectiva

Se eliminó el trabajo manual de registrar pedidos: Python calcula y archiva todo solo.

✓

Código simple y local

Un solo archivo app.py logra el backend; no requiere base de datos ni nube.

✓

Escalable

Agregar productos es editar JSON; podría migrarse a SQLite o sumar un panel de ventas.

Conclusión general: se demostró que con pocas herramientas de Python (Flask + openpyxl) es posible transformar una página web estática en un sistema funcional que resuelve un problema real de negocio: capturar, validar y almacenar pedidos de forma automática y trazable. El proyecto evidencia cómo la automatización reduce errores, ahorra tiempo y sienta la base para futuras mejoras como bases de datos, reportes o notificaciones.
